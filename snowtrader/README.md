# Snow Rush · Surf Rush

שני עולמות, ותפריט פתיחה (`index.html`) שבוחר ביניהם:
- **Snow Rush** (`snow.html`): כפר סקי, רכבל, מסלולים ופארק, סנובורד. הפירוט בהמשך.
- **Surf Rush** (`beach.html`): עיירת חוף לטייל בה. כל סשן נמשך 3 דקות. פירוט ב-`HANDOFF.md`, והמספרים מהמחקר על גלים, גולשים וקייטים ב-`RESEARCH.md`.
  - **גלישת גלים** (מבית הספר לגלישה): הגלים נשברים בהדרגה, השפה נזרקת מעל הקיר ויוצרת צינור, ויש קצף, ריסוס וערפל. חותרים, קמים, רוכבים על הקיר, מאטים כדי להיכנס לצינור, ועושים סיבובים וקפיצות מהשפה. המצלמה מצלמת מהערוץ כמו בסרטי גלישה (🎥 / C: מאחור).
  - **קייטסרף** (מבית הספר לקייט): קייט של 12 מ' עם סטרטים וברידל, בר, chicken loop ורתמה. רוח, קפיצות, 360, בקרול ותפיסות.
  - **העיירה** בהשראת הטיילת של תל אביב: מגדלי מלונות, דקלים, תחנות הצלה, יפו בקצה המפרץ. אנשים הולכים, עוקפים זה את זה ואת השחקן, ומשחקים כדורעף ומטקות.
- **ארנק אחד וטיסות:** מה שמרוויחים בכל עולם נכנס לארנק משותף (🪙). קונים בו לוחות, וכרטיס טיסה (750 🪙) לעולם השני: `flight.html` הוא כרטיס עלייה, המראה, שיוט מעל העננים, ירידה דרך הענן אל חוף תל אביב או עמק הסקי, ונחיתה בעולם השני.

## Snow Rush · סנובורד

משחק סנובורד תלת־ממדי לנייד ולמחשב, יורדים במסלול, מבצעים תרגילים באוויר, אוספים גבישי קרח ומתחמקים מקוצי קרח, סלעים ועצים, וצוברים ניקוד עד קו הסיום.

- **עצמאי לגמרי:** HTML + JS סטטי, בלי build ובלי שרת. תיקיית `snowtrader/` נפרסת כפרויקט Vercel משלה (Root Directory = `snowtrader`).
- **טכנולוגיה:** three.js r128 (כלול ב־`lib/`), מנוע הרינדור, האפקטים והתנועה מבוססים על משחק הקניון של `stockgame` (ענף `claude/mobile-3d-game-2s1dmh`): ACES + sRGB, אור מבוסס־תמונה פרוצדורלי, composer עם bloom וגרייד, סולם איכות לפי FPS, ג׳ויסטיק צף ומצלמת מעקב מרוככת, הדמות (`hero-m.glb`) עם שלד בסגנון Mixamo.
- **שמירה:** `localStorage` (ניקוד כולל, שיאים, לוחות שנקנו).

## ריאליזם
- מהירויות לפי נתוני גולשים: ממוצע ~33 קמ״ש (מתחילים ~20, מתקדמים ~45); כל מסלול מכוון למהירות סופית אחרת (ירוק ~43, כחול ~58, אדום ~72, שחור ~86 קמ״ש).
- לפני כל ריצה עולים ברכבל (חבל ~5 מ׳/ש׳, מוצג בהאצה פי 12, אפשר לדלג).
- אתר סקי: בקתות וקפה עם מרפסות, תור לרכבל, גדרות רשת, תותחי שלג, גולשים.

## שליטה
| פעולה | נייד | מחשב |
|---|---|---|
| סיבוב | גרירה בצד שמאל | A / D או חיצים |
| התכופפות (מהירות) | גרירה למעלה | W / ↑ |
| קפיצה | כפתור קפיצה (קצה הרמפה = Perfect Pop) | רווח |
| באוויר: ספין | ימינה / שמאלה | A / D |
| באוויר: סלטה | למעלה / למטה | W / S |
| תפיסה | החזקת "תפיסה" | Shift / E |

## מבנה
- `js/world.js` ההר: מסלול כפונקציה של מרחק, רמפות, צ׳אנקים, עצים, שמיים, הרים, שלג
- `js/rider.js` הרוכב, הלוח, פוזה פרוצדורלית לפי צירי עולם
- `js/main.js` פיזיקה, טריקים, ניקוד, מצלמה, HUD, תפריט, תוצאות
- `js/audio.js` צליל מסונתז בלבד (רוח, מטבעות, נחיתה, מוזיקת סינת׳ווייב)
- `js/engine.js` רנדרר, אור, post-processing, סולם איכות

cd snowtrader && python3 -m http.server 8123
