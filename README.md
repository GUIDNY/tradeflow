# TapIt · חנות מוצרי NFC

חנות אונליין (עברית, RTL) למוצרי NFC: כרטיסי ביקור חכמים, מעמדי ביקורות גוגל, שלטי תפריט,
מדבקות, תגים, טבעות ואביזרים. נבנתה על React + Vite + Tailwind + shadcn/ui מעל תשתית Base44.

## מה יש בפנים

| דף | נתיב | תיאור |
| --- | --- | --- |
| בית | `/` או `/Home` | hero, קטגוריות, רבי־מכר, מבצעים, המלצות ו־CTA |
| חנות | `/Shop` | 17 מוצרים עם חיפוש, סינון לפי קטגוריה ומחיר ומיון |
| עמוד מוצר | `/Product?id=<id>` | גלריה, מפרט, טאבים, מלאי ומוצרים משלימים |
| עגלה | `/Cart` | עדכון כמויות, הסרה, מד התקדמות למשלוח חינם |
| תשלום | `/Checkout` | טופס עם ולידציה, שיטות משלוח ותשלום, אישור הזמנה |
| איך זה עובד | `/HowItWorks` | הסבר על NFC, קהלי יעד, משלוחים והחזרות, שאלות נפוצות |
| צור קשר | `/Contact` | טופס פנייה עם ולידציה וערוצי תקשורת |

## ארכיטקטורה

- `src/lib/products.js` — קטלוג המוצרים, הקטגוריות, עיצוב מחיר וסף המשלוח החינם.
- `src/lib/CartContext.jsx` — ניהול העגלה (הוספה, כמות, מחיקה, סכומים) עם שמירה ב־`localStorage`.
- `src/lib/nav.js` — בניית נתיבים בפורמט של Base44 (`/PageName?param=value`).
- `src/components/store/ProductArt.jsx` — איורי SVG שנוצרים מהפלטה של כל מוצר, במקום תמונות חיצוניות.
- `src/components/store/` — Header, Footer, מגירת עגלה, כרטיס מוצר, דירוג וכמות.
- `src/Layout.jsx` — מעטפת RTL משותפת לכל הדפים.
- `src/pages.config.js` — רישום הדפים והלייאאוט עבור הראוטר של Base44.

התשלום ושליחת הטופס הם הדגמה בצד הלקוח בלבד — אין קריאה לשרת ואין שמירת פרטים.

## הרצה מקומית

```bash
npm install
npm run dev      # פיתוח
npm run build    # בילד לפרודקשן
npm run lint     # בדיקת קוד
```

לחיבור לבקאנד של Base44 יש ליצור `.env.local`:

```
VITE_BASE44_APP_ID=your_app_id
VITE_BASE44_APP_BASE_URL=your_backend_url
```

תיעוד Base44: https://docs.base44.com/Integrations/Using-GitHub
